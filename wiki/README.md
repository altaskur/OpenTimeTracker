## ✏️ Contributing to Wiki

The wiki is part of the repository and follows the same contribution process:

1. **Fork the repository**
2. **Create a branch**: `git checkout -b docs/wiki-update`
3. **Edit wiki files** in the `wiki/` directory
4. **Follow Markdown best practices**
5. **Update in both languages** (English and Spanish)
6. **Submit pull request** to `develop` branch

### Wiki Style Guide

- Use clear, concise language
- Include code examples where appropriate
- Add screenshots for UI features
- Keep formatting consistent
- Update cross-references when adding new pages
- Maintain bilingual content
